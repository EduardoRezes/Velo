Iniciar o projeto

Comandos uteis do playwrigth

Executa os testes
- yarn playwrigth test

Executar testes na interface do playwrigth
- yarn playwrigth test --ui 

Executa os testes no modo visualização
- yarn playwrigth test --head

Executa os teste passo a passo
- yarn playwrigth test --debug

Executar em modo criativo(codegen)
- yarn playwrigth codegen <link da aplicação>

Para ajustar o Timeout dos testes:
Ex buscar um elemento em tela, por defaul o playwrigth seta 30 segundos nativamente, caso queira ajustar, deve:
1 - Abri arquivo playwrigth.config.ts
2 - Adicionar dentro de defineConfig
3 - Inserir timeout: 5000,
